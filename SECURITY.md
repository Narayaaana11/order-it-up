# Security Policy

## Reporting Security Issues

Please report security issues responsibly. Contact the project maintainers privately with a description of the issue, reproduction steps, and expected impact.

## Best Practices for Running Order It Up

- **Local Network Only:** Keep local API (`:3001`), Kitchen Display System (`:3002`), and Tableside server (`:3003`) ports protected within your local business network (LAN/Wi-Fi).
- **Device Security:** Protect the counter workstation running the database.
- **Backups:** Use the automated backup features in Settings to safeguard your database.
