# Contributing to Order It Up

Thank you for your interest in improving **Order It Up**!

## Development Guidelines

1. **Coding Style:** Clean TypeScript / React with standard formatting.
2. **Offline Safety:** Ensure all core point-of-sale functionality works completely offline without network dependencies.
3. **Database Integrity:** Any schema additions must include proper SQLite migration handling.
4. **Testing:** Test table flows, receipts, and order statuses locally before submitting pull requests.

## Workflow

1. Fork or branch from `main`.
2. Implement your feature or fix.
3. Test using `npm run dev`.
4. Submit a descriptive pull request.
