# Order It Up Frontend

> **Touchscreen Interface for Order It Up Restaurant POS** — built with Next.js 16, React 19, Tailwind CSS, and shadcn/ui.

## 🚀 Overview

This package contains the Next.js renderer application for **Order It Up**. It serves as the primary user interface across counter checkout, dine-in table ordering, menu management, customer profiles, and system settings.

It runs as a local client communicating directly with the Order It Up Express backend (`:3001`), Kitchen Display System (`:3002`), and Tableside Waiter server (`:3003`).

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (React 19)
- **State Management:** Zustand
- **Styling:** Tailwind CSS + Radix UI primitives
- **Icons:** Lucide React
- **Internationalization:** `use-intl`

## 💻 Development

```bash
# Start Next.js development server
npm run dev
```
